FFmpeg and the Python library yt-dlp are required.

Edit the following directories in the 'download.bat' file to suit you
FFmpeg location: C:\ffmpeg\bin\ffmpeg.exe
yt-dlp location: C:\Users\tadee\AppData\Local\Programs\Python\Python312\Scripts\yt-dlp.exe 
Channels: C:\YTConv\auto\channels.txt
Archive: C:\YTConv\auto\archive.txt
Download folder: C:\YTConv\auto\download

In 'channels.txt' input a list of links to the video tabs of channels you wish to download the latest two videos from,
delimited by a new line, like so: 

<------------------->
https://www.youtube.com/@channel1/videos
https://www.youtube.com/@channel2/videos
<------------------->

Following appropriate edits, run 'download.bat' to start the script.
